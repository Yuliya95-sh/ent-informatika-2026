# ЕНТ Информатика 2026

Интерактивное пособие для подготовки к ЕНТ по информатике по спецификации 2026 года (Казахстан): 13 тем в 6 разделах, теория, разборы задач, блоки «Ловушки ЕНТ», тренажёры на 633 задания, тесты по каждому из 6 разделов на 100 заданий и пробный тест ЕНТ на 40 заданий с таймером.

## Как открыть

- **Онлайн:** https://yuliya95-sh.github.io/ent-informatika-2026/
- **Офлайн:** скачайте [`ENT_Informatika_2026.html`](ENT_Informatika_2026.html) (кнопка «Download raw file» на странице файла) и откройте в браузере. Это всё пособие в одном файле, интернет не нужен.

Прогресс по темам хранится в браузере, на котором вы решаете задания.

## Статистика учеников

Ученик один раз указывает имя и класс, после этого его ответы и результаты пробных тестов отправляются в Google Таблицу учителя. Сводка открывается на странице «Кабинет учителя» по паролю. Сайт собирает только имя, класс и баллы. Код для таблицы и инструкция по установке — в файле [`google-apps-script.gs`](google-apps-script.gs).

## Формат теста (спецификация ЕНТ 2026)

| Формат | Заданий | Баллов |
|---|---|---|
| Один правильный ответ | 25 | 25 |
| Задания на основе контекста | 5 | 5 |
| Один или несколько правильных ответов | 5 | 10 |
| Установление соответствия | 5 | 10 |
| **Итого** | **40** | **50** |

## Сверка с учебниками

Материалы сверены с учебниками информатики 7–11 классов (ЕМН) издательств Арман-ПВ и Атамұра. Найденные в учебниках ошибки и неточности отмечены прямо в темах. Тексты учебников в репозиторий не входят: все задания составлены заново.

## Файлы

- `index.html` — оболочка и движок страницы (её показывает GitHub Pages)
- `data/` — содержание тем и задания: `s*.js` — основа, `d*.js` — углубление, `tb*.js` — дополнения по учебникам, `contexts.js` — задания на основе контекста
- `ENT_Informatika_2026.html` — всё пособие одним файлом для скачивания
